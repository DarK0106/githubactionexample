** CD **
이미지를 가지고 운영 서버에 실제로 배포하는 행위




한 줄 요약

코드를 push하면 → 빌드 → 테스트(여기까지가 CI) → 배포(이게 CD)까지 
자동으로 해주는 컨베이어 벨트

CI/CD = CI(지속적 통합) + CD(지속적 배포) 의 줄임말이에요.

CI (Continuous Integration, 지속적 통합)

코드를 합칠 때마다 자동으로 빌드하고 테스트해서, 깨졌는지 바로 알려주는 거예요.

- 오늘 한 거: gradlew build로 jar 만들고, 잘 도는지 확인 → 이걸 손으로 했죠
- CI: push만 하면 이걸 GitHub가 알아서 해줌. 빌드 실패하면 빨간불로 알려줌.

CD (Continuous Deployment/Delivery, 지속적 배포)

빌드·테스트 통과한 걸 자동으로 서버에 올려서 실행까지 하는 거예요.

- 오늘 한 거: docker build → docker run으로 컨테이너 띄움 → 이것도 손으로
- CD: 그걸 자동으로. push하면 알아서 이미지 만들고 서버(AWS 등)에 배포.
